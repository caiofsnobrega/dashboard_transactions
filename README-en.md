# Power BI | E-commerce Transactions Dashboard

### Power BI dashboard featuring KPIs and interactive charts based on transaction data from a US-based e-commerce store.

*[View the Portuguese version here](README.md)*


![Dashboard](images/dash_transacoes-print.png)


### Project Objective:
The project aimed to present key indicators and charts based on sales transaction data from a US e-commerce store. The dataset includes information on product categories, transaction values ​​(in US dollars), the state where the sale took place, and buyer details such as gender and profession.


![States_GIF](images/capture_transacao_estados.gif)


### Key Challenges:
I processed the dataset in Power Query and created measures to generate the KPIs. For the repurchase indicator, for example, I used a formula to calculate the ratio of unique customers to the total number of transactions, using the result to determine the percentage of customers who made more than one purchase.
